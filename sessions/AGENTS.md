# Discussion and recording rules

Read this guide when discussing ideas or recording a session, even when no file will be edited. Read [canon rules](../canon/AGENTS.md) for validation, branches, approval, and retcons; read [format and language rules](../templates/AGENTS.md) before writing content.

## Workflow

- **During discussion**: talk; write nothing yet unless the user explicitly requests an edit, except for autonomous forecast maintenance under the [forecast guide](../forecasts/AGENTS.md). Flag conflicts with applicable canon the moment you see them. A request to edit repository guidance does not by itself close the worldbuilding session or approve its ideas.
- **When recording**: apply the [wiki lifecycle and classification rules](../wiki/AGENTS.md). Record useful partial ideas without waiting for certainty. Session logs preserve how the discussion developed; wiki entries carry the current formulation. Record substantive draft retirements and their reasons in the session log rather than retaining obsolete wiki pages.
- **End of session** (the user signals they are done, or the topic closes): write the session log and reconcile the wiki with the session, creating or updating drafts and preserving alternatives still under exploration. Apply the canon guide to changes affecting approved claims. Add unresolved checks to `open-questions.md` and reconcile checks affected by merged or removed entries. Then list entries added, changed, moved, merged, or removed and their scopes. Draft recording and maintenance do not require canon approval; the user may approve or reject content without selecting a single future.
- **Forecasts**: when a session affects existing predictions, reconcile them using the [forecast guide](../forecasts/AGENTS.md) and record material revisions and their reasons in the session log.

Commit once per session, message `session: <topic>`.

## Session logs and open questions

- Use [the session template](../templates/session.md) at `sessions/YYYY-MM-DD-<topic>.md`. Follow the template guide's language rules for session logs.
- Record the ideas discussed, validation results, decisions and their scope, entries created or changed, and open questions. Preserve alternatives that remain viable rather than implying a single chosen future.
- Before recording wiki entries, read [wiki rules](../wiki/AGENTS.md); before recording stories, read [story rules](../stories/AGENTS.md).
- For [open-questions.md](../open-questions.md), follow its existing question format and the canon guide's distinction between viable alternatives and unresolved checks. Identify affected branches. When a check is resolved, remove its open question and link the entry that records the resolution.
