# Discussion and recording rules

Read this guide when discussing ideas or recording a session, even when no file will be edited. Read [canon rules](../canon/AGENTS.md) for validation, branches, approval, and retcons; read [format and language rules](../templates/AGENTS.md) before writing content.

## Workflow

- **During discussion and exploration**: actively propose hypotheses, second-/third-order extrapolations, and competing branches alongside discussing the user's ideas. You may write or extend `draft` wiki entries (following [wiki rules](../wiki/AGENTS.md)) and `forecasts/` trees (following [forecast rules](../forecasts/AGENTS.md)) directly whenever a substantive idea or extrapolation is worth capturing — no per-idea confirmation is required. Distinguish real-world observations, user premises, and agent extrapolations, and flag conflicts with applicable `canon` the moment you see them. Leave `canon` claims and `canon/timeline.md` untouched until user approval. A request to edit repository guidance does not by itself close the worldbuilding session or approve its ideas.
- **When recording**: apply the [wiki lifecycle and classification rules](../wiki/AGENTS.md). Record useful partial ideas and agent extrapolations without waiting for certainty. Session logs preserve how the discussion developed; wiki entries carry the current formulation. Record substantive draft retirements and their reasons in the session log rather than retaining obsolete wiki pages.
- **End of session** (the user signals they are done, or the topic closes): write the session log and reconcile the wiki and forecasts with the session, creating or updating drafts, capturing agent extrapolations, and preserving alternatives still under exploration. Apply the canon guide to changes affecting approved claims. Add unresolved checks to `open-questions.md` and reconcile checks affected by merged or removed entries. Then list entries and forecast trees added, changed, moved, merged, or removed and their scopes, clearly separating user premises from agent extrapolations. Draft recording, autonomous extrapolation, and maintenance do not require canon approval; the user may approve or reject content without selecting a single future.
- **Forecasts**: create new forecast trees or reconcile existing ones using the [forecast guide](../forecasts/AGENTS.md) whenever discussion, evidence, or forward extrapolation warrants it, and record material revisions and their reasons in the session log.

Commit once per session, message `session: <topic>`.

## Session logs and open questions

- Use [the session template](../templates/session.md) at `sessions/YYYY-MM-DD-<topic>.md`. Follow the template guide's language rules for session logs.
- Record the ideas discussed (distinguishing user premises from agent extrapolations), validation results, decisions and their scope, entries and forecasts created or changed, and open questions. Preserve alternatives that remain viable rather than implying a single chosen future.
- Before recording wiki entries, read [wiki rules](../wiki/AGENTS.md); before recording stories, read [story rules](../stories/AGENTS.md).
- For [open-questions.md](../open-questions.md), follow its existing question format and the canon guide's distinction between viable alternatives and unresolved checks. Identify affected branches. When a check is resolved, remove its open question and link the entry that records the resolution.
