# 2126 年在未達耗材里程碑後仍未達家戶門檻

這是尚未展開的葉節點，不表示之後擴張的機率為零；月球以外的路徑亦未被排除。

## 情境與判定

在 2036 年達成 S、2076 年未達 L 後，2126 年**未達 H**。月球仍可能保有科研、機器活動、輪班人員或較小社群。允許後來出現在地生產：未達 2076 年門檻，不表示 2126 年仍沒有 L。縮減或撤離若使 H 未達標，也屬本結果。

依根節點的完整標準於 **2126-12-31** 判定；資料不足時維持 unresolved，不能把沒有報導當成失敗證據。繼承全部前置路徑，但先前期限的里程碑不保證此後始終維持。

## 機率與依據

**條件機率：85%；信心：極低。** 85% 的補集較重視這段歷史累積的經費、健康、供應與家戶偏好障礙。這是範圍較廣的其餘結果，不是預測有 85% 機率撤離或文明衰退。可負擔、可持續的家戶服務證據會提高另一分支的比重。

這是根據 [[forecasts-tw/index]] 的選擇性證據與 repo 推論所作的主觀起始估計，未經頻率校準；估計條件包括完整前置路徑，而非只看直接父節點。

## 驗證與修訂訊號

應使用 H 的居住紀錄，而非把缺少在地氧氣當成沒有家戶的證明。[[wiki-tw/concepts/lunar-base-development]] 區分工作基地與定居點；[[wiki-tw/concepts/space-expansion-motives]] 保留地球中心替代方案。追蹤永久居住問題，尤其是健康、運輸、失去贊助後的經費與權利。此路徑尚未建模 3026 年結果。
