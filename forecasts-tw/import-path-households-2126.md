# 2126 年在未達耗材里程碑後出現家戶居住

根節點：[[forecasts-tw/index]] · 父節點：[[forecasts-tw/no-local-consumables-2076]]

這是尚未展開的葉節點，不表示之後擴張的機率為零；月球以外的路徑亦未被排除。

## 情境與判定

在 2036 年達成 S、2076 年未達 L 後，2117–2126 年**達成 H**。進口、補貼、社群財力或後來的在地生產都可能支撐居住。檔名的「進口路徑」指較早的歷史，不要求持續依賴進口，也不排除 2076 年後達成 L。

依根節點的完整標準於 **2126-12-31** 判定；資料不足時維持 unresolved，不能把沒有報導當成失敗證據。繼承全部前置路徑，但先前期限的里程碑不保證此後始終維持。

## 機率與依據

**條件機率：15%；信心：極低。** 15% 為動機與經費充足的家戶保留路徑，即使較早未達耗材里程碑也可居住。相較於在地供應歷史，此機率較低是因為先前已示範的有利能力較少，不是認為物理上進口與定居不相容；也不是估計在地生產的因果效果。

這是根據 [[forecasts-tw/index]] 的選擇性證據與 repo 推論所作的主觀起始估計，未經頻率校準；估計條件包括完整前置路徑，而非只看直接父節點。

## 驗證與修訂訊號

[[wiki-tw/society/community-led-settlement]] 允許居住本身就具有價值；若選擇就業贊助，[[wiki-tw/society/migration-contracts-and-resident-rights]] 要求可執行的供應與退出安排。須驗證家戶預算、運輸持續性、醫療與長期棲地表現。不假設已有對地出口產業、便宜的軌道運輸或可無限期運作的生命維持系統。
