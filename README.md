# Spark

A hard-science exploration of possible futures for human civilization across the universe, written as a wiki, with stories set in those futures.

**Rule:** everything follows known physics — see [canon/laws.md](canon/laws.md).

## Layout

- [canon/](canon/) — the laws of physics we obey and the master timeline.
- [wiki/](wiki/) — entries on eras, technology, society, places, and concepts.
- [stories/](stories/) — fiction set in the world, linked to the entries it relies on.
- [sessions/](sessions/) — a log of each discussion that shaped the world.
- [open-questions.md](open-questions.md) — unresolved evidence, feasibility checks, and decisions within branches.
- [templates/](templates/) — page templates.

## How it grows

The wiki is an evolving workspace: useful ideas can become short `draft` entries while assumptions and validation remain open. Entries are classified by subject and can be revised, split, merged, moved, or removed as the discussion develops. Session logs preserve the discussion history. A draft becomes `canon` only after approval; substantive replacements of approved content follow the retcon rules. See [AGENTS.md](AGENTS.md) for the recording workflow and other agent rules.

Browse it in any Markdown viewer, or open the folder as an [Obsidian](https://obsidian.md) vault for `[[wikilinks]]` and a graph view.
